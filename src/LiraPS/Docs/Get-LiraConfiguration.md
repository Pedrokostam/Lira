# Get-LiraConfiguration

## SYNOPSIS

Gets the currently active LiraPS configuration.

## SYNTAX

### __AllParameterSets

```
Get-LiraConfiguration [<CommonParameters>]
```

## DESCRIPTION

Retrieves the currently active LiraPS configuration.
This configuration determines the Jira server connection and authentication details used by other cmdlets.

## EXAMPLES

### Example 1

Get-LiraConfiguration

Returns the currently active configuration details.
